# 爆款大师模块功能开发需求文档

> 基于 umi6 平台 (wbazuv.mdd.umi6.com) "生产部门 > 爆款大师" 三个子模块的逆向分析
> 文档版本: v1.0 | 日期: 2026-05-30

---

## 1. 系统概述

### 1.1 模块定位
"爆款大师"是DynaXAI平台 **生产部门** 下的核心超级员工（AI Agent），提供一站式短视频爆款创作能力。入口为侧边栏 `生产部门 > 爆款大师`，路由 `/a9b0c1d2e3f4a5b6c7d8e9f0a1b2c3d4/209`。

### 1.2 技术栈分析（原站）

| 层级 | 原站技术 | 我们的对应 |
|------|----------|-----------|
| **前端框架** | Vue 3 + Naive UI（n-input, n-button, n-tabs, n-menu） | Vue 3 + Naive UI（已一致） |
| **状态管理** | Pinia | Pinia |
| **路由** | Vue Router（hash mode） | Vue Router |
| **HTTP** | Axios + Bearer Token | Axios |
| **后端** | PHP（ThinkPHP 风格）/ 自研 API 网关 | NestJS |
| **存储** | 阿里云 OSS / MinIO | MinIO / OSS |
| **AI 视频引擎** | Seedance 2.0（字节跳动火山引擎） | 需对接火山引擎 API |
| **AI 对话** | 自研 RAGFlow + 多 LLM（DeepSeek/Qwen/豆包等） | 自研 AI Provider |
| **认证** | Token-based（手机号+密码/验证码登录） | JWT |

### 1.3 三个子模块总览

| # | 模块名 | target_url | 核心功能 |
|---|--------|-----------|---------|
| 1 | 一键追爆 | `one_click_viral` | AI 对话引导 → 爆款内容创作 |
| 2 | 一键大片 · 国内版 | `one_click_masterpiece_v2` | AI 视频生成（Seedance 2.0 引擎） |
| 3 | 一键大片 · 国际版 | `one_click_masterpiece` | AI 视频生成（国际版引擎） |

## 4. 模块三：一键大片 · 国际版

### 4.1 功能定位
与国内版类似的 AI 视频生成工作台，但面向国际市场，使用国际版 AI 视频模型引擎。路由 target_url 为 `one_click_masterpiece`。

### 4.2 与国内版的差异点

| 差异项 | 国内版 | 国际版 |
|--------|--------|--------|
| target_url | `one_click_masterpiece_v2` | `one_click_masterpiece` |
| AI 视频引擎 | Seedance 2.0（字节跳动火山引擎国内） | 国际版引擎 |
| 版本选项 | 基础版/稳定版/全能版 | 待确认（可能相同） |
| 模型选项 | seedance2.0 / seedance2.0 fast | 国际版模型 |
| 内容策略 | 适配国内平台（抖音/快手/小红书） | 适配国际平台（TikTok/Instagram/YouTube） |
| 算力计费 | 可能不同 | 可能不同 |

### 4.3 功能点清单

国际版的功能点与国内版 **基本一致**（GN-01 ~ GN-64），额外增加以下差异项：

| ID | 功能点 | 优先级 | 描述 |
|----|-------|--------|------|
| GJ-01 | 国际版引擎对接 | P0 | 对接国际版 AI 视频生成 API |
| GJ-02 | 国际平台适配 | P1 | 视频比例/时长/风格适配 TikTok/Instagram/YouTube |
| GJ-03 | 多语言创意描述 | P2 | 支持中英文创意描述输入 |
| GJ-04 | 国际版模型选择 | P1 | 国际版专用模型列表 |

### 4.4 后端 API 设计

与国内版共用大部分 API，通过参数区分：
- 素材/任务相关 API 完全共用
- 视频生成 API 增加参数 `edition=domestic|international`
- 模型列表 API 返回时区分国内/国际模型

interface Material {

## 10. 非功能性需求

| 需求 | 描述 |
|------|------|
| 性能 | 视频生成任务提交响应 < 2s；SSE 首字输出 < 1s |
| 并发 | 支持同时提交多个视频生成任务（队列管理） |
| 存储 | 单文件上传限制 500MB，单用户素材总量 10GB |
| 安全 | 素材上传需校验文件类型；创意描述需敏感词过滤 |
| 可靠性 | 视频生成任务需支持失败重试；任务状态需持久化 |
